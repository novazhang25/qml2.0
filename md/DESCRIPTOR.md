# Descriptor calculation and saved T repair

**H2S loader compatibility:** Run 1 now uses the already saved sulfur Ne-core-excluded
subspace: S 3s/3p and both H 1s AOs, at stored indices `[2,6,7,8,9,10]`.
Its H2S valence block and FE width are 6, with selection after the full-AO
Löwdin transformation. This loader-only repair leaves the 1s-only descriptor
producer described below unchanged; no descriptor data or electronic-structure
calculations are regenerated. Ne-core AO exclusion here does not change
`RMP2(mf, frozen=0)` or FCI settings.

`codes/descriptor.py` provides calculation and saved-data repair modes. Normal calculation performs no scientific validation or automatic smoke-test gate. Independent checks live in `tests/test_descriptor.py`. Solver convergence settings remain part of the calculation; convergence status is recorded without an acceptance check.

Inputs are the existing scan geometries and energy metadata in `results/initialdata`. Original inputs and FCI energies are not modified. RHF and RMP2 use the full STO-3G space with no frozen orbitals. Both second-order consistent and standard PySCF RDMs are saved. Matrices and tensors are constructed in the full AO space, the Löwdin transformation is performed in that full space, and only then is the retained AO block selected for descriptor extraction. The HF-reference connected tensor from the consistent RDM supplies the tensor transformation.

The post-Löwdin descriptor space excludes only AOs satisfying `Z > 2 and principal == 1`. H 1s is retained; heavy-atom 2s, 2p, 3s, 3p and higher shells are retained. The saved `core_indices` identify descriptor exclusions only. AO exclusion does not imply occupied-MO freezing: MP2 continues to use `RMP2(mf, frozen=0)` and the full occupied correlation space, and the FCI frozen-core settings remain unchanged. `ao_selection_rule` records `post-lowdin-exclude-Z-gt-2-principal-1-only-v1` in each calculated record and its manifest.

The legacy implementation retained only the highest principal shell on each heavy atom, a uniform chemical-core descriptor rule. H retained 1s; Li–F retained 2s/2p and excluded 1s; S retained 3s/3p and excluded 1s/2s/2p. For the second-period atoms present in the benchmark this is equivalent to excluding 1s, but for sulfur it also excludes 2s and 2p. The revised rule explicitly excludes only heavy-atom 1s AOs. The legacy H2S result follows the same highest-shell rule applied to every atom, rather than a sulfur-specific branch.

H2S alone changes: stored S 2s, 2px, 2py and 2pz indices `[1,3,4,5]` are additionally retained, alongside S 3s/3p and both H 1s AOs. Production-specific selection, legacy comparisons, dimension, and full-AO-first tests are in `tests/test_descriptor_ao_selection.py`; the archived Methods reference retains its historical shell rule. Existing production descriptor data are not regenerated by this terminology and regression-test update.

The stored rank-4 tensor keeps PySCF ordering: `Lambda_raw[p,q,r,s] = Lambda_methods[p,r,q,s]`. Methods 4.1 requires `T[i,j,k] = Lambda_methods[i,j,k,k] = Lambda_raw[i,k,j,k]`, without summing over `k`. The producer transposes a view to Methods ordering before taking the last-two-axis diagonal. `T_munulambda` retains the existing lexicographic `i < j < k` selection in saved valence-local order. No rank-4 storage or non-T descriptor convention changes.

The corrected output location is `results/descriptor-v2-methods-t`. Existing `results/descriptor` records retain the old T extraction and are preserved. To repair the existing 270 records using their saved full rank-4 tensors, without rerunning electronic-structure calculations:

```sh
/Users/novaz/Desktop/qml2.0/.venv-rhf/bin/python /Users/novaz/Desktop/qml2.0/codes/descriptor.py --repair-t
```

Use `--source-dir` (an alias of `--input-dir`) to select saved descriptors, `--output-dir` to select a new destination, and `--audit-only` for validation without writing. Repair mode cannot be combined with calculation/resume options.

The repair refuses to overwrite an existing output directory and writes its independent audit alongside the corrected records. It preserves the existing AO selection; T-only repair cannot expand an old H2S descriptor from 6 to 10 AOs. Production resume refuses manifests with an old or unknown T mapping or AO selection rule.

Calculate all molecules in the 1s-only descriptor space using a new output directory:

```sh
/Users/novaz/Desktop/qml2.0/.venv-rhf/bin/python /Users/novaz/Desktop/qml2.0/codes/descriptor.py --output-dir /Users/novaz/Desktop/qml2.0/results/descriptor-1s-only
```

Append `--molecules H2O --geometry-id 001` for one geometry, or `--dry-run` to list selected inputs without calculations or output writes. After starting this new dataset, `--resume` with the same output directory skips existing completed records without inspecting their tensors. Add `--rerun-failed` to retry execution failures.

The default output directory is `results/descriptor-v2-methods-t`, separate from previous Methods 4.1 outputs. Each geometry has an NPZ record and JSON status file; each molecule has `summary.csv`, and the dataset has `manifest.json`. NPZ records retain full-space matrices, both RDM tracks, cumulants, Löwdin intermediates, AO selection indices and labels, and descriptors. The recomputed RHF energy is named `E_RHF_calculated`.

In normal calculation mode, no success or validation status label is written; resume uses saved files and execution errors. Metadata records `validation_performed=false`; no validation report or numerical residual audit is generated. The separate `--repair-t` mode validates saved arrays and writes `t_repair_audit.json`. File protection and execution-error handling remain enabled.
